技术亮点

  1. 自监督预训练：Point-CMAE 双掩码重建 + VICReg 分布正则（γ 目标方差 0.5→1.0 让特征更分散）
  2. 概念树 = 概念抽象，不是类聚类：苹果碎片应抽象进"水果"概念而非"纯苹果簇"——为此纠正了评估框架（同类叶 LCA → 概念包含率）
  3. 物理描述子定义概念：12 维确定性描述子（形状/尺度/朝向/颜色），属性方差小 = 该属性即概念 → 自动识别重复分支（孪生分支 cos 0.93）
  4. 开放世界理解：近义类 OOD 泛化极好（towels→towel、dining table→table）；新颖类给出诚实的"物理概念 + 归属区域"

如何体验

  1. 认识未见物体：打开 ood.html，切换下拉选择 7 个训练集外物体，看系统如何"理解"它们
  2. 概念树浏览器：打开 tree.html，展开概念树、点任意节点看成员/类分布/物理概念/语言描述
